Idea. Your class votes for a pizza topping. Cheese gets three votes, pepperoni gets six, and vegetables get two. The most popular choice is the mode. The mode is the value that occurs most often. Here the mode is pepperoni, not six. Six is how many times it appeared. With numbers, tally each value. Take the scores three, five, three, eight, three and five. Three appears three times. Five appears twice. Eight appears once. So the mode is three. A set of data can have two modes, if two values tie for the most. It can have no mode, if every value appears once. The mode is not affected by extreme values. This question type says calculate the mode, or state how you would find the mode.

Method. Step one: tally how often each value appears in the data set the question names. Step two: pick the value with the highest count. Step three: give the value, not the count. Tallying stops you missing a repeated value. The trap is giving the frequency instead of the value. If five appears three times, the mode is five, not three.

Worked example. Here is a real exam question. Davide studies attitudes to unhealthy food before and after a school ban. Ten young people rate their attitude from one to ten. We calculate the mode for the ratings before the ban. It is worth one mark. Step one. Use the right column. Here are the ten ratings before the ban. Ignore the after-ban ratings. Step two. Tally each rating. Four appears once. Six once. Seven four times. Eight twice. Nine once. Ten once. Check the total. One plus one plus four plus two plus one plus one makes ten, the number of participants. Step three. Pick the highest count. Seven appears most often, four times. So the mode is seven. A tempting wrong answer is four. Seven appears four times, but four is the frequency. The mode is the value itself, so the answer is seven. Now the exam-ready answer. The mode is seven. It appears four times, more than any other rating. This explanation is by olevels dot com, not an official mark scheme.

Common mistake. A common mistake is using the wrong column. In Davide's table, the ratings after the ban have a mode of five. That is the after column. The question asked about before the ban, so the answer is seven.

Your turn. Now you try. This one has no table. You must state how you would find the mode in a set of data. Write your answer, then choose Continue to Answer.

Answer. Here is an example. The scores are two, three, three, five, three and seven. Tally them. Three appears three times. Every other score appears once. The answer is to find the value that appears most often. You can tally each value to do this. Here the mode is three. A common wrong answer is to put the values in order and pick the middle one. That describes the median. The mode is about how often a value appears, not about its position. So it loses the mark. So tally each value. Find the highest count. Give the value. The same method works for words, such as the most popular pizza topping.
