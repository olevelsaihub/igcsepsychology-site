Idea. Think of a rumour passing round school. By the time it reaches you, the story has changed. Memory can do the same thing inside one head. In nineteen thirty-two, Bartlett proposed the Theory of Reconstructive Memory. It says memory is not an exact recording. When we recall, we rebuild the memory. So details can be changed, added or left out. What does the rebuilding? Schemas. A schema is a mental framework built from past experience and culture. Your dog schema might say dogs are big and noisy. Memory fills the gaps using it. Bartlett tested this with a story called The War of the Ghosts. Twenty British participants read a Native American folk story, then reproduced it several times. This is repeated reproduction. The recall got shorter, unfamiliar details changed to fit British culture, so canoes became boats, and unusual details were missed out. A question describes a person whose memory changed. It asks you to explain why, using the theory.

Method. Step one: spot exactly what changed. This is your evidence. Step two: say that recall is rebuilt using schemas, so memory can change. Step three: name the schema that fits. Step four: link it to the change. Each mark has a job. One mark is for the theory. One is for linking a schema to this person. The trap is saying the person is lying. They are not. Their memory has been rebuilt.

Worked example. Here is a real exam question. Leah is six. She sees a small dog that does not bark. Later she says a large dog barked at her and made her cry. We must explain why her memory changed, using the Theory of Reconstructive Memory. It is worth two marks. Step one: spot what changed. The dog was small and silent. Leah recalls a large dog that barked, and says she cried. Step two: state the theory. Memory is not an exact copy. Recall is rebuilt using schemas, so details can change. Step three: name the schema. Leah probably has a schema that dogs are big, noisy and scary. When she recalled, she filled the gaps with it. A tempting wrong route is to say Leah is lying, or has a bad memory. Reject it. The theory says everyone rebuilds memories. She believes what she says. Now the exam answer. Theory first. Then Leah's schema. Then the changed details. One mark is for the theory. One mark is for linking Leah's schema to the changed details. This explanation is by olevels dot com, not an official mark scheme.

Common mistake. The most common mistake is to say the person has a bad memory, or made it up. That earns no theory mark. The answer must say the memory was rebuilt using a schema.

Your turn. Now you try. Ellis is told a long story about an elephant with strange events. He wants to tell it to his father the next day, with all the parts in order. Explain what is likely to happen to his memory, using Bartlett's study. Write your answer, then choose Continue to Answer.

Answer. Ellis will not recall it exactly. Bartlett found recall is shorter, unusual details are missed out, and the order stays fairly well. So Ellis will probably drop odd details, like the lemurs playing guitars, and keep the main order. A common wrong answer says Ellis will forget it, or remember it perfectly. Neither uses the study. The theory says the story is rebuilt, so it changes. So, spot the change. Say recall is rebuilt using schemas. Name the schema. Link it to the change.
