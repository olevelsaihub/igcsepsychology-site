Idea. Two football teams each score three goals a game on average. Team A scores two, three, three and four. Team B scores nought, one, five and six. The average is the same, but Team B is more spread out. How spread out data are is called dispersion. The range is one way to measure it. The range is the highest value minus the lowest value. Team A: four minus two is two. Team B: six minus nought is six. The range is one number, not two. Use only the data set the question names. It might be one column, or one group. Quiz A scores are four, nine and six: range five. Quiz B scores are twenty, twenty two and thirty: range ten. If the question names Quiz B, the answer is ten. One extreme value can make the range large. This question type says calculate the range for one set of data. The set might be a column in a table, or the ages in the study.

Method. Step one: find the highest value in the named data set. Step two: find the lowest value in the same set. Step three: subtract the lowest from the highest. Write the units if the data have them, such as marks or years. The trap is using the first and last values in the list. They are not always the highest and lowest. Search the whole set for the biggest and the smallest.

Worked example. Here is a real exam question. Davina studies homework time and test scores. We calculate the range for the end of topic test scores. It is worth one mark. Step one. Find the highest test score. Looking across all ten scores, the highest is thirty, for participant G. Step two. Find the lowest test score. The lowest is nine, for participant F. Step three. Subtract. Thirty minus nine is twenty one. The range is twenty one marks. A tempting wrong route is to use the homework time column. Its highest value is eighty and its lowest is fifteen, so sixty five. But the question asks for test scores, so that column is wrong. Now the exam-ready answer. The highest test score is thirty and the lowest is nine. Thirty minus nine equals twenty one. This explanation is by olevels dot com, not an official mark scheme.

Common mistake. A common mistake is to write the range as two numbers, such as nine to thirty. The range is one number. Subtract, and give twenty one.

Your turn. Now you try. Savannah asks people about music and happiness. Her participants were aged between eighteen and sixty five. Calculate the range for the age of all participants. Write your answer, then choose Continue to Answer.

Answer. All participants means the whole sample, aged eighteen to sixty five. The youngest is eighteen, and the oldest is sixty five. Sixty five minus eighteen is forty seven years. A common wrong answer is seven, from twenty five minus eighteen. That uses only the youngest third of the sample. The question asks about all participants, so the oldest age, sixty five, must be used. So find the highest and the lowest in the named set. Then subtract. Check that your answer is one number, and add the units.
