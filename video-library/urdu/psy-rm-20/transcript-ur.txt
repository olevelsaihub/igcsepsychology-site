Idea۔ Bar chart الگ الگ categories دکھاتا ہے، جیسے English یا Sociology کے students۔ bars کے درمیان gaps ہوتے ہیں۔ Histogram continuous data دکھاتا ہے، جیسے منٹوں میں وقت۔ اس کی bars آپس میں ملی ہوتی ہیں۔ ہر axis کو units کے ساتھ label اور برابر scale چاہیے۔ Scatter diagram ہر شخص کے دو measures plot کرتا ہے۔ ہر شخص ایک point ہے۔ homework پر گزارا گیا وقت ایک axis پر جاتا ہے، اور test score دوسرے پر۔ Frequency table گنتا ہے کہ ہر category کتنی بار ہوئی۔ اس میں categories کا column، tally کا column اور total کا column ہوتا ہے۔ Distribution scores کی shape ہے۔ Normal distribution میں shape symmetrical bell ہوتی ہے، اور mean، median اور mode برابر ہوتے ہیں۔ Positive skew میں زیادہ تر scores کم ہوتے ہیں، اور tail دائیں طرف ہوتی ہے۔ Negative skew میں زیادہ تر scores زیادہ ہوتے ہیں، اور tail بائیں طرف۔ اس question type میں table یا chart مکمل کرنے یا بنانے، یا distribution کا نام بتانے کو کہا جاتا ہے۔ Marks labels، اچھی scale اور درست data پر ملتے ہیں۔
