Idea۔ ایک photo flat ہوتی ہے، پھر بھی آپ بتا سکتے ہیں کہ درخت لڑکے کے پیچھے ہے۔ آپ کا brain clues سے depth پڑھتا ہے۔ Depth cues وہ clues ہیں جو retina پر ایک flat image کو تین dimensional دنیا کے طور پر دیکھنے دیتے ہیں۔ Monocular cues وہ depth cues ہیں جو صرف ایک آنکھ سے کام کرتے ہیں۔ جاننے کے لیے پانچ monocular cues ہیں۔ Superimposition۔ Relative size۔ Linear perspective۔ Texture gradient۔ اور height in the plane۔ Superimposition کا مطلب ہے overlap۔ جو object دوسرے کے پیچھے جزوی طور پر چھپا ہو، اسے زیادہ دور سمجھا جاتا ہے۔ Relative size کا مطلب ہے کہ دو ملتی جلتی چیزوں میں سے جو چھوٹی لگے، اسے زیادہ دور سمجھا جاتا ہے۔ Linear perspective یہ ہے کہ parallel lines، جیسے سڑکیں یا railway tracks، افق پر vanishing point پر ملتی نظر آتی ہیں۔ Texture gradient یہ ہے کہ قریب کی سطحیں واضح، موٹی detail دکھاتی ہیں، اور دور کی سطحیں باریک، ہموار اور دھندلی لگتی ہیں۔ پانچواں cue height in the plane ہے۔ Horizon line کے قریب کی چیزیں منظر میں نیچے کی چیزوں سے زیادہ دور لگتی ہیں۔ Question میں ایک منظر دیا جاتا ہے، اور cue کا نام لینے اور Explain کرنے کو کہا جاتا ہے کہ وہ depth کیسے دکھاتا ہے۔

Answer۔ Superimposition کا مطلب ہے ایک object دوسرے پر overlap کرتا ہے اور اسے جزوی طور پر چھپا دیتا ہے۔ Brain جزوی طور پر چھپے object کو زیادہ دور، اور سامنے والے پورے object کو قریب سمجھتا ہے۔ مثلاً اگر ایک شخص car کے سامنے کھڑا ہو اور اس کا کچھ حصہ چھپا دے، تو car دور لگتی ہے۔ عام غلط جواب کہتا ہے کہ superimposition وہ ہے جب objects overlap کریں، اور وہیں رک جاتا ہے۔ یہ نہیں بتاتا کہ یہ depth کیسے دکھاتا ہے۔ کچھ students اسے الٹ بھی دیتے ہیں، اور کہتے ہیں کہ چھپا ہوا object قریب ہے۔ تو cue کا نام لیں اور define کریں۔ Objects کی طرف اشارہ کریں۔ انہیں so سے جوڑیں۔
