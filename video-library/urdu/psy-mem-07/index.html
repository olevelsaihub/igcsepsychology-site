Method۔ Step ایک، term کو ایک واضح sentence میں define کریں۔ Step دو، memory سے ایک example شامل کریں، یا فرق کے question میں whereas کا لفظ استعمال کر کے دوسری term define کریں۔ ہر step کا ایک mark ہے۔ Examiners واضح، مکمل sentences دیکھتے ہیں۔ Trap holism کو بس سب کچھ دیکھنا کہہ کر define کرنا ہے۔ آپ کو کہنا ہوگا کہ حصے interact کرتے ہیں، اور مانگا جائے تو example دینا ہوگا۔

Worked Example۔ یہ ایک real exam question ہے۔ Psychology میں استعمال ہونے والی term reductionism کو Define کریں، اور example استعمال کریں۔ دو marks۔ Step ایک، define کریں۔ ایک پیچیدہ behaviour کو چھوٹے، سادہ حصوں میں توڑ کر explain کرنا۔ Step دو، example۔ Multi-store Model، memory کو تین الگ stores میں بانٹ کر explain کرتا ہے۔ ایک tempting غلط راستہ یہ کہنا ہے کہ reductionism کا مطلب سب کچھ اکٹھا دیکھنا ہے۔ اسے reject کریں۔ یہ holism ہے۔ Reductionism اس کا الٹ ہے۔ Exam answer۔ Definition کے لیے ایک sentence۔ Example کے لیے ایک sentence۔ اگر question holism مانگتا، تو آپ پورے behaviour والا idea define کرتے۔ پھر example کے طور پر reconstructive memory استعمال کرتے، کیونکہ schemas، emotion اور culture سب ہمارے recall پر اثر کرتے ہیں۔ definition کا ایک mark۔ Multi-store example کا ایک mark۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ عام غلطی holism کو سب کچھ دیکھنا کہہ کر define کرنا ہے۔ یہ بہت مبہم ہے۔ Holism کا مطلب ہے پورے کو study کرنا، اور یہ کہ حصے کیسے interact کرتے ہیں۔ Memory کے لیے، emotion، culture اور schemas سب ایک دوسرے پر اثر کرتے ہیں۔
