Idea۔ آپ کا brain ایک school کی طرح ہے جس میں departments ہیں، اور ہر department کا ایک کام ہے۔ cortex، wrinkled بیرونی layer ہے۔ یہ چار lobes میں بٹی ہے، یعنی بڑے حصے۔ یہ frontal، parietal، temporal اور occipital lobes ہیں۔ ہر lobe جوڑے میں ہے، brain کی ہر طرف ایک۔ ان کے نیچے، پیچھے کی طرف، cerebellum ہے۔ Frontal lobes، planning، decisions، personality اور voluntary movement سنبھالتے ہیں، یعنی وہ حرکت جو آپ اپنی مرضی سے کرتے ہیں۔ ان میں Broca's area ہے، جو speech پیدا کرتا ہے۔ Temporal lobes، hearing، language سمجھنا اور memory سنبھالتے ہیں۔ Parietal lobes، touch، pain، temperature، pressure اور spatial awareness سنبھالتے ہیں، یعنی چیزوں کی جگہ کا پتا ہونا۔ Occipital lobes، بالکل پیچھے ہیں، اور vision سنبھالتے ہیں: colour، shape اور movement۔ Cerebellum، balance، coordination اور movement کا باریک control سنبھالتا ہے، جیسے سوئی میں دھاگا ڈالنا۔ کوئی region damaged ہو تو شخص کو اس region کے function میں مسئلہ ہوتا ہے۔ اسی سے ہم پتا لگاتے ہیں کہ کون سا region damaged ہے۔ Question میں کچھ tests ہوتے ہیں جن میں شخص اچھا یا برا کرتا ہے۔ آپ نے فیصلہ کرنا ہے کہ کون سا region damaged ہے، اور اس کے function سے وضاحت کرنی ہے۔

Method۔ پہلا step: وہ task ڈھونڈیں جس میں شخص برا ہے، اور وہ tasks جن میں اچھا ہے۔ دوسرا step: کمزور ability کو اس lobe یا cerebellum سے match کریں جو ذمہ دار ہے۔ تیسرا step: task کی details سے وضاحت کریں کہ وہ region کیوں damaged ہوگا۔ Traps یہ ہیں: parietal اور occipital کو آپس میں بدل دینا، region کا نام لکھنا مگر function نہ لکھنا، جن tasks میں اچھا تھا انہیں نظر انداز کرنا، اور cerebellum کو lobe کہنا۔

Worked Example۔ یہ ایک real exam question ہے۔ Sandy ایک patient کا test کرتی ہے جس کے Region G میں damage ہے۔ وہ recall اور pressure میں اچھا ہے، مگر colour کا نام بتانے میں برا۔ ہم نے explain کرنا ہے کہ کون سا region damaged ہے، اور اس کے function کا حوالہ دینا ہے۔ دو marks۔ پہلا step: results کو الگ کریں۔ Colour naming برا تھا۔ Recall اور pressure ٹھیک تھے۔ دوسرا step: match کریں۔ Colour دیکھنا vision ہے، اور occipital lobes vision سنبھالتے ہیں۔ Pressure ٹھیک تھا، اس لیے parietal lobes کام کر رہے ہیں۔ Recall ٹھیک تھا، اس لیے temporal lobes کام کر رہے ہیں۔ ایک tempting غلط راستہ یہ کہنا ہے کہ parietal ہے، کیونکہ colour test میں حواس استعمال ہوتے ہیں۔ لیکن pressure test اچھا ہوا، اور touch parietal کا کام ہے۔ Colour، vision ہے، جو occipital ہے۔ Parietal کو reject کریں۔ Exam answer۔ پہلے region اور function، پھر tests سے link۔ ایک mark اس کا ہے کہ occipital lobes، vision سنبھالتے ہیں۔ ایک mark خراب colour naming کو damage سے link کرنے کا۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔
