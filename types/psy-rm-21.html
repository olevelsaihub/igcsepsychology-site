Narrow sample

Weakness
One school's students may not represent adults.
Effect
Lower generalisability.

Standardised

Strength
Everyone heard the same words.
Effect
Easier to repeat: more reliable.

Baseline measure

Strength
Sam can measure the change for each student.
Effect
Change is more likely due to the music: more valid.

Students can help

Weakness
Classmates might whisper answers.
Effect
Scores may not show each student's own memory.

4

The method

  1. Find a feature

    Who, where, what task, how it was measured.

  2. Name it

    Say if it is a strength or a weakness.

  3. Explain the effect

    Link it to reliability, validity or generalisability.

  4. Keep it about this study

    Use the names and details from the question.

Do not lose marks here

  • ✗
    Generic point

    "The sample was small" with no study detail.

  • ✗
    No link

    An effect that does not follow from the feature.

  • ✗
    Same idea twice

    Two points must use two different features.

Written-answer check

After your attempt, see the full worked explanation

Worked explanation

  1. Strength: same test at start and end gives a baseline.
  2. Why: improvement can be measured for the same students, so the effect of the task is clearer.
  3. Weakness: students worked in groups in lessons and could help each other.
  4. Why: test scores may reflect help, not the task difficulty.
Model answer · written by olevels.com, not an official Pearson mark scheme

Strength: Alessia tested the students on the new concept at the start and again when the week finished, so she had a baseline. This means she could measure how much each group actually improved, so any change is more likely to be due to the task, which increases validity. Weakness: The students did the activities in groups during normal lessons, so they could have helped or distracted each other. This means Alessia cannot be sure the end-of-week scores were caused by the difficulty of the task rather than by help from classmates.

How the marks are earned

One mark for each identified strength or weakness and one for each linked justification.
