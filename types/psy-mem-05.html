The method

  1. Spot the change

    What differs from what happened, and what expectation does it fit?

  2. State the theory

    Recall is rebuilt using schemas.

  3. Name the schema

    Say which schema caused this change.

  4. Know the study

    Sample, story, method and what changed.

Worked explanation

  1. The dog was small and did not bark, but Leah recalls a large barking dog.
  2. Theory: recall is rebuilt using schemas.
  3. Leah's dog schema (big, barking, scary) filled in the details.
Model answer · written by olevels.com, not an official Pearson mark scheme

The Theory of Reconstructive Memory says memory is not an exact copy; we rebuild memories each time we recall them, using our schemas, so the memory can change. Leah probably has a schema of scary dogs as big and noisy and making children cry, so when she recalled the event she filled in those details and said a large dog barked at her.

How the marks are earned

One mark for stating that recall is reconstructed using schemas; one mark for linking Leah's dog schema to the changed details.
