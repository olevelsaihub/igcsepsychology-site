Knowledge card

Correlations and scatter diagrams

Written

A correlation tests whether two measured co-variables are related. Positive: both rise together. Negative: one rises as the other falls. It never proves cause.

4

The method

  1. Name both

    Say what the two co-variables are.

  2. Read left to right

    Points going up is positive; going down is negative.

  3. Read values carefully

    Use the grid lines and count each point.

  4. Write in context

    Describe the pattern with the variable names.

Do not lose marks here

  • ✗
    Claiming cause

    Related does not mean one causes the other.

  • ✗
    IV and DV

    Both variables are measured: call them co-variables.

  • ✗
    Grid-line points

    Count points on a line carefully.
