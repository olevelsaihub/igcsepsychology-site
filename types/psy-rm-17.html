Finding the mode

Calculation

The mode is the value that appears most often. The answer is the value itself, not how many times it appears.

1

Value or count?

Decide first, then tap the ? to check.

3 cells to find

Find the mode, the number that is only a count, and the runner-up.

  1. Mode = 5
  2. A count, not the mode
  3. Second, not the mode

Why
5 has the highest count.

A count, not the mode

Why
3 is how often 5 appears.

Second, not the mode

Why
4 appears twice; 5 appears three times.

2

Finding it

Mode = the value with the highest count

Tap a part to see what it means and how to find it.

  • Use only the set the question names.
  • Two values tie: give both. All appear once: no mode.

Try itFind the mode of 2, 7, 7, 3, 7, 3.

  1. Tally: 2 once, 3 twice, 7 three times
  2. 7 has the highest count
  3. Mode = 7

Does it score?

5

The method

  1. Pick the set

    Use only the column or group asked for.

  2. Tally each value

    A tick for every time it appears.

  3. Pick the highest count

    Write the value, not the count.

Do not lose marks here

  • ✗
    Count, not value

    The answer is the score itself.

  • ✗
    Missed one

    Tick values off as you tally.

  • ✗
    Wrong average

    Most often is the mode; the middle is the median.
