Two sequences to know: input → processing → output, and encoding → storage → retrieval. Never mix terms from the two.

The method

  1. Recall both sequences

    Input-processing-output and encoding-storage-retrieval.

  2. Check the neighbours

    The boxes next to the gap show which sequence it is.

  3. Define in one sentence

    Say what happens to information at that stage.

Do not lose marks here

  • ✗
    Mixed sequences

    'Encoding' never sits between input and output.

  • ✗
    Retrieval as storing

    Retrieval brings information out; storage keeps it.

  • ✗
    Storage vs encoding

    Encoding changes the form; storage holds it.
