Worked explanation

  1. Define reductionism: breaking a complex behaviour into simpler parts.
  2. Give a memory example.
Model answer · written by olevels.com, not an official Pearson mark scheme

Reductionism is explaining a complex behaviour by breaking it down into its smaller, simpler parts. For example, the Multi-store Model explains memory by dividing it into three separate stores: a sensory store, a short-term store and a long-term store.

How the marks are earned

One mark for the definition, one mark for the Multi-store Model example.
