Knowledge card

Visual illusions and visual constancies

Written

A visual illusion is when what we see does not match the real object. Visual constancy is seeing size, shape or colour as unchanged when the image changes.

Ambiguous figure

Key point
Two readings, only one seen at a time.

Distortion

Key point
Length, size or angle is misjudged.

Fiction

Key point
We see something that is not there.

Ambiguous too

Write it as
It can be seen two ways and the view flips.

Exam tipNot every illusion is ambiguous: check what the viewer experiences.

Shape constancy

Key point
The image changes shape, but we see a rectangle.

Size constancy

Key point
The image shrinks, but the person does not.

Colour constancy

Write it as
The brain allows for the light, so it looks red.

Exam tipFor colour constancy, always mention the change in lighting.

4

The method

  1. Name it

    Name the illusion type or the constancy.

  2. Say what happens

    A flip, a misjudged length, or an unchanged colour or shape.

  3. Tie to the object

    If there is a scenario, name the exact object.

Do not lose marks here

  • ✗
    Constancy is not an illusion

    Constancy keeps perception steady; an illusion misleads.

  • ✗
    Both at once

    An ambiguous figure shows only one reading at a time.

  • ✗
    Forgot the light

    Colour constancy answers must mention different lighting.

Written-answer check

Worked explanation

  1. Define colour constancy: colour is seen as stable though the light reaching the eye changes.
  2. Explain how: the brain allows for the lighting, using past experience of the object's real colour.
Model answer · written by olevels.com, not an official Pearson mark scheme

Visual constancy means our visual system keeps an object's colour looking the same even though the light it reflects into our eyes changes. For example, a banana in a dim room sends darker light to the eye than in sunshine, but the brain adjusts for the lighting and uses what it already knows about bananas, so we still see it as yellow.

How the marks are earned

Mark 1 for stating that colour is perceived as stable despite changing input; mark 2 for explaining that the brain compensates for lighting/past experience, with an example.
